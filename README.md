# SkyForm

A modern form builder web application built with React, Vite, and Tailwind CSS.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, React Router
- **Backend:** Firebase (Auth, Firestore, Storage)
- **Integration:** Google Sheets API, Google Drive API

## Getting Started

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your Firebase credentials
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the dev server:
   ```bash
   npm run dev
   ```

## Build for Production

```bash
npm run build
```

## Environment Variables

See `.env.example` for all required variables.

## Features

- Authentication (Email/Password, Google OAuth)
- Drag-and-drop form builder with 20+ question types
- Form settings (theme, background, validation, etc.)
- Live preview (desktop/tablet/mobile)
- Public form pages with validation
- Response dashboard with CSV/Excel export
- Google Sheets integration (auto-append responses)
- Google Drive integration (file uploads)
- Dark/light theme
- QR code sharing
